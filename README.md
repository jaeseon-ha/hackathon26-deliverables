## Part 1 — small problems + testing (`part1/`)

| File | What it does |
|---|---|
| `speedingticket.py` | Reads a speed limit and a driving speed, prints the ticket amount (0 / 50 / 75 / 150 / 300). |
| `heatingcooling.py` | Prompts for daily temperatures until a value below -459, then prints heating-day and cooling-day totals. |
| `countinput.py` | `countchars(st)` counts characters excluding spaces, periods, `!` and `,`; main asks for a string and prints the count. |
| `stocktrading.py` | `maxProfit(prices)` returns the best single buy-then-sell profit, or 0. |

Every file has a header docstring, in-line comments, and a `run_tests()` function with
black-box and clear-box tests. Run the tests with:

```bash
python part1/speedingticket.py test
python part1/heatingcooling.py test
python part1/countinput.py test
python part1/stocktrading.py test
```

Run a program normally by omitting `test` (e.g. `printf '35\n45\n' | python part1/speedingticket.py` prints `75`).

## Part 2 — discovery process (`part2/`)

| File | What it is |
|---|---|
| `MatPlotLib discovery - filled.pdf` | The worksheet with all answers filled in (open in Adobe Reader or any viewer that renders form fields). |
| `fill_worksheet.py` | Script that writes the answers into the blank worksheet's form fields (`pip install pypdf`). |
| `discovery.py` | Models 1–3 as a plain Python program; `python discovery.py save` writes every figure as a PNG. |
| `discovery_notebook.ipynb` | Jupyter notebook version, executed, with all plots and the College Scorecard analysis. |
| `model1_*.png`, `model2_*.png`, `model3_*.png` | Figures generated by `discovery.py`. |

`scorecard.csv` (~100 MB) is **not** included; copy it from the original repository's `part2/`
folder next to `discovery.py` / the notebook before running them. Key facts used in the worksheet:

- 6,274 lines (1 header + 6,273 institutions), 3,308 columns
- `UGDS` is column index 290 (spreadsheet column KE); 5,478 integer values, 795 `NA`
- Range 0 – 163,164; largest: Southern New Hampshire University

Requirements: `numpy`, `matplotlib` (and `jupyter` for the notebook, `pypdf` for the fill script).
